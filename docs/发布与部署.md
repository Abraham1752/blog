# 发布与部署

## 架构

```
src/content/posts/*.md  ──►  Astro 7 静态构建  ──►  dist/  ──►  GitHub Pages
                        （双皮肤 × 双主题、字体子集、Mermaid 内联 SVG）
```

- 站点：<https://abraham1752.github.io/blog/>
- 仓库：<https://github.com/Abraham1752/blog>（branch `main`）
- 部署：`.github/workflows/deploy.yml`，push main 或手动 dispatch

## 发布步骤

```bash
npm run build && npm run preflight   # 本地全检
git add -A
git commit                            # 常规提交信息即可
git push                              # 触发 Actions，约 1 分钟上线
```

验证：<https://github.com/Abraham1752/blog/actions> 看到 `Deploy to GitHub Pages` success 后，
访问 https://abraham1752.github.io/blog/（CDN 缓存可能延迟数分钟）。

## 手动重部署（无代码改动）

GitHub 仓库 → Actions → Deploy to GitHub Pages → Run workflow。

## 字体子集化

标题 CJK 字体（`src/assets/fonts/noto-{serif,sans}-sc-700.woff2`）只含
`scripts/fonts-src/charset.txt` 收录的字符。**每次新增中文内容都要重跑**：

```bash
node scripts/build-charset.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/subset-cjk.ps1
```

- 源文件：google/fonts 的 `NotoSerifSC[wght].ttf` / `NotoSansSC[wght].ttf`（24MB/17MB，不入库）
- 流程：可变字体 instancer 固定 700 → pyftsubset 站点字符集 → woff2
- 漏检保护：`npm run preflight` 会比对文章字符集 ⊆ 字体子集，缺失即失败

## 网络环境备忘

- `github.com`、`api.github.com`、`raw.githubusercontent.com`、`registry.npmjs.org`、`cdn.jsdelivr.net`、PyPI 可达
- `release-assets.githubusercontent.com`、华为云镜像不可达（下载 GitHub Release 附件走 jsdelivr 或 raw）
- Windows PowerShell 执行策略拦截 `.ps1`：用 `powershell -NoProfile -ExecutionPolicy Bypass -File` 调用
- npm 命令用 `npm.cmd`（PowerShell 会拦截 `npm.ps1`）
