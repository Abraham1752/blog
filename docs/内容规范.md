# 内容规范

## 新文章流程

1. 复制 `src/content/posts/template-01-post.md`（或 02/03/04）
   → 命名 `YYYY-MM-DD-短横线slug.md`（如 `2026-08-10-majsoul-review.md`）
2. 填写 frontmatter（约束见下），正文从 `##` 开始
3. `draft: true` 期间本地预览：`npm run dev`（草稿在构建中不出现）
4. 定稿后去掉 `draft: true`
5. **重跑字体子集化**（新增中文字符后必做）：
   ```bash
   node scripts/build-charset.mjs
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/subset-cjk.ps1
   ```
6. 本地验证：`npm run build && npm run preflight`
7. `git add -A && git commit && git push`（触发自动部署）

## frontmatter 约束

| 字段 | 约束 | 说明 |
| ---- | ---- | ---- |
| `title` | 20–80 字 | 文章标题 |
| `pubDate` | 日期 | 发布日期 |
| `updatedDate` | 日期，可选 | 大改时更新（sitemap lastmod 用它） |
| `description` | 40–160 字 | 摘要：列表页 / SEO / 社交卡片 |
| `excerptEn` | 可选 | 英文一句话摘要（供 OG/外链场景） |
| `category` | 枚举 | `复盘` / `教程` / `测评` / `周记` / `片段` |
| `tags` | 3–8 个 | 标签；太多会稀释归档页权重 |
| `projects` | 可选数组 | 关联 `projects.yaml` 的 slug，文章与项目互链 |
| `draft` | 默认 false | true 时不出现在构建产物 |
| `noindex` | 默认 false | 搜索引擎收录控制 |

## 写作约定

- 正文一律用中文全角标点；代码、专名（Astro、GitHub、Mermaid）保留原文
- 一级标题由页面模板渲染（模板 03 的骨架 `##` 起）
- Mermaid 图：` ```mermaid ` 代码块，构建期渲染为内联 SVG（亮暗各一份）
- 图片放 `src/assets/`，用 Astro `Image` 组件（webp + 尺寸约束）
- 正文走系统字体（CJK），**标题**走子集字体——新字符必须重跑子集化，否则回退宋体/黑体

## 分类定位

- `复盘`：项目/事件回顾，重结论与取舍
- `教程`：可跟着做的步骤，配代码/图
- `测评`：工具/方法试用报告
- `周记`：短周期记录，轻结构
- `片段`：碎片思考，一句话也能发

## 项目关联

`projects.yaml` 三个字段决定项目页展示：`status`（进行中=柠檬黄 / 已完成=IKB / 归档=灰）、`tech`、`posts`（建议留空，靠文章的 `projects` 字段自动反向关联，避免两处维护）。
