## 为什么是现在

我一直有一个习惯：把折腾过的东西记下来。翻旧硬盘的时候找到几年前的笔记，看着那些"当时觉得稀松平常、现在完全想不起来"的细节，才意识到记录这件事本身有多值钱——不只是给别人看，更是给未来的自己留线索。

过去半年我用 AI 做了不少小东西：抓包解析网络协议的工具、自动化研究流水线、一堆 UI 视觉实验。东西做完就堆在 GitHub 上，想法散在备忘录里。这次决定把它们收拢到一个地方，正式一点地写。

## 这个站点是什么

**Yikino** 是一个关于"用 AI 开发小玩具"的日志站：

- **复盘**：项目做完之后回头看，什么决定是对的、什么是踩坑
- **教程**：可以跟着做的步骤，配代码和示意图
- **测评**：对工具、方法、工作流的试用报告
- **周记 / 片段**：短周期的记录和碎片思考

技术上是 Astro 静态构建，推送到 GitHub 自动部署，没有评论、没有统计、没有登录。写作即 git push——这大概是一个程序员博客最顺滑的发布流程了。

## 设计上的两个决定

**双皮肤**。展示层用瑞士国际主义：米白底、IKB 蓝、柠檬黄、硬边框、点阵网格，理性、直接、有秩序感；阅读层用电子墨水：暖纸色、衬线标题、赭石强调、68 字符行宽，温暖、舒展、适合长时间读。两种皮肤都支持亮暗主题，暗色下文字级强调一律柠檬黄，保证对比度。

**字体自托管**。拉丁字体走本地打包的 woff2，中文标题字体会按本站实际用字做子集化（当前约 550 个字符，90–120KB），正文走系统字体。没有第三方字体 CDN，加载快，也少一层依赖。
